| Action | Syntax or shortcut |
| --- | --- |
| Focus capture on Mac | `⌘K` |
| Focus capture on Windows/Linux | `Ctrl+K` |
| Tuck the thought | `Enter` by default |
| New line | `Shift+Enter` by default |
| Browser extension | `Alt+Shift+T` |
| Add a tag | `#tag` |
| Mention a person | `@person` |
| File into a brain during capture | `/brain` |
| Repeat daily | `~daily` |
| Repeat weekly | `~weekly` |
| Repeat monthly | `~monthly` |
| Create a todo directly and skip the suggestion | Prefix with `*`, `todo:`, or `/todo` |

Nested tags and brains can match by any segment, so a short token can still find a deeper path.

Repeat tokens also mark the capture as an explicit todo. For automatic todo suggestions, see [Why a thought looks actionable](/reference/actionable-detection).
