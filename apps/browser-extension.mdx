The Tuck browser extension is a capture tool, not a second Tuck app.

<Card title="Install Tuck for Chrome" icon="chrome" href="https://chromewebstore.google.com/detail/tuck/aoilpgipnmdcphndjkhfeoldjgclnbii">
  Add the Tuck browser extension from the Chrome Web Store.
</Card>

The Chrome Web Store version works with Chromium browsers such as Chrome, Edge, Arc, and Brave. Tuck also supports Firefox.

## Clip a page

Open the extension or press `Alt+Shift+T`.

If text is selected, Tuck captures the selection and the page URL. If nothing is selected, it captures the URL.

Before you tuck it, you can add a brain, tags, people, a todo, or a calendar date.

## If the page already exists in Tuck

The extension can show thoughts that already mention the same page so you can open them instead of creating a duplicate.

## When the vault is locked

Keep Tuck unlocked in a browser tab when you want clips sealed immediately. If Tuck is locked or closed, the extension queues the clip locally until Tuck is available again.

The badge shows how many clips are waiting.

## Choose a date

In Chrome Web Store version **0.1.6**, select **Date** to open a calendar inside the popup. Use the month arrows and choose a day, select **Today**, or select **Clear** to remove the date.

The calendar stays within the popup. This fixes the Vivaldi issue where clicking a day outside the popup closed it instead of selecting the date.

Version **0.1.6** was published on the Chrome Web Store on October 9, 2026. These version details apply to the Chrome Web Store build.

The web app uses the page title to name a saved clip when one is available, including clips of selected text. That behavior does not depend on the new date picker.
